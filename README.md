# ⛽ Útulná Benzínka – Na cestách

Útulná webová hra v češtině s ovládáním klikáním na předměty, mapou 8 zastávek, obchodem s doplňovacími stojany, najímáním zaměstnanců a vylepšováním stanice.

## 🌐 Hraní online (GitHub Pages)
Po zapnutí **GitHub Pages** na větvi `main` je hra dostupná na adrese:
`https://<tvoje-jmeno>.github.io/benzinka/`

> Účty a postup se při hraní na GitHub Pages automaticky ukládají lokálně do prohlížeče hráče (`localStorage`), případně lze hrát i bez přihlášení jako host.

## 💻 Lokální spuštění se sdíleným ukládáním účtů (`server.js`)
```bash
node server.js
```
Poté otevři `http://127.0.0.1:3000`.
